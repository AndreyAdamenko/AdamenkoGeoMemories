# AdamenkoGeoMemories: переносимая версия

Приложение располагается в отдельной папке `_GeoMemories` внутри архива фотографий:

```text
Photos/
  папки с фотографиями...
  _GeoMemories/
    start-server.bat
    config.local.json
    .geo-memories-app
    server/
    dist/
    node_modules/          # включает Node.js 24, ExifTool и обработчик превью
    data/
      catalog.sqlite      # каталог, описания, теги, альбомы и координаты
      thumbnails/         # перенесённые и новые миниатюры
      backups/
```

Запустите `start-server.bat` двойным щелчком и откройте **http://127.0.0.1:3210**. Устанавливать Node.js или npm и пересобирать интерфейс на другом компьютере не требуется. Комплект предназначен для **Windows x64**. Подложка OSM загружается через интернет; каталог и фотографии доступны локально.

Для переноса сохраняйте весь архив вместе с `_GeoMemories`. Буква диска и имя родительской папки могут измениться. Приложение определяет архив по родительской папке, обновляет корневой путь в базе, сохраняя ID фотографий, описания, теги, альбомы, ручные координаты и кэш. Относительные пути фотографий внутри архива должны сохраняться.

Настройки переносимой версии:

```json
{
  "sourceRoot": "..",
  "dataDir": "./data",
  "portable": true,
  "port": 3210,
  "importConcurrency": 2
}
```

Пути вычисляются относительно папки приложения. Файл `.geo-memories-app` обозначает папку программы: импорт пропускает её целиком, включая зависимости, миниатюры и резервные копии. Не удаляйте этот маркер. `.geo-memories-data` обозначает собственную папку данных приложения.

Оригиналы фотографий используются только для чтения. После сверки всех перенесённых файлов прежняя папка данных сохраняется как резервная в `.deployment-backups` репозитория. Там же остаётся отдельная согласованная копия исходной базы. Настройки рабочей копии в репозитории направляются на новую папку данных, чтобы рабочая база и новые миниатюры сохранялись на переносном диске. Старый кэш в резервной копии больше не используется приложением.

Запускайте один экземпляр приложения для этой базы. Перед отключением диска остановите сервер через `Ctrl+C` и дождитесь завершения. Делайте резервную копию базы через «Настройки и копии»: оригиналы фотографий не содержат добавленных описаний и тегов.

## Обновление из исходного проекта

При остановленном сервере выполните из репозитория:

```powershell
npm run check
npm test
npm run build
./scripts/deploy-portable.ps1 -ArchiveRoot 'D:\Photos'
```

Скрипт копирует программу и зависимости в `_GeoMemories`, проверяет перенос данных по SHA-256 и записывает отчёт. При обновлении существующая переносимая база сохраняется. Изменённая сборка запускается тем же батником. Переносимая папка не содержит исходный архив повторно, отчёты аудита или настройки Codex.
