# Участие в разработке

Спасибо за интерес к AdamenkoGeoMemories.

1. Создайте fork и отдельную ветку.
2. Установите зависимости: `npm ci`, затем `npm run setup`, если системный Node.js старее 24.
3. Укажите тестовую папку фотографий в `config.local.json`. Не используйте единственную копию ценных данных для экспериментов.
4. Запустите `npm run dev` и откройте http://127.0.0.1:5173.
5. Перед pull request выполните `npm run check`, `npm test`, `npm run build`.

Изменения должны сохранять принцип чтения оригиналов без записи. Миграции каталога должны сохранять подписи, теги, альбомы и ручные координаты. Добавляйте проверки для изменений импорта, географических фильтров и переносимости.

В описании pull request укажите проблему, изменение поведения и выполненные проверки. Вклад принимается на условиях GPL-3.0-only, как и остальной код проекта.

## Сообщения об ошибках

Укажите версию Windows, Node.js, шаги воспроизведения и текст ошибки. Замените личные пути нейтральными примерами. Не прикладывайте фотографии, точные координаты, базы SQLite, JSON-экспорты, отчёты аудита или токены. Для воспроизведения используйте синтетические изображения либо специально подготовленные материалы без личных метаданных.
